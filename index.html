How to Select Parts of Images

Selection Tools for Precise Editing

In today's class, you will learn how to select specific parts of your photocopier experiments:

What is a selection? A selection is like drawing a line around part of your image. This lets you edit only that part without changing the rest of your image.

Selection Tools Tutorial

Watch this tutorial to learn about selection tools in Photoshop
Tool 1: Magic Wand Tool

Perfect for selecting areas in high-contrast photocopies:

  1. Select Magic Wand Tool (W)
  2. Set Tolerance (20-40 is good for photocopies)
  3. Click on a black or white area
  4. Hold Shift to add more areas
  5. Hold Alt/Option to remove areas
Tool 2: Quick Selection

Quickly select areas by painting:

  1. Select Quick Selection Tool (also under W)
  2. Paint over the area you want to select
  3. Adjust brush size with bracket keys [ and ]
  4. Good for larger areas in photocopies
Tool 3: Select Color Range

Select areas based on color - perfect for high-contrast photocopies:

  1. Go to Select → Color Range
  2. From the "Select" dropdown, choose "Shadows" (for black areas) or "Highlights" (for white areas)
  3. Adjust the "Range" slider to control how much gets selected
  4. Adjust "Fuzziness" slider (try 40-80 for photocopies)
  5. Click OK to create your selection
  6. This works much better than Magic Wand for detailed areas
Tool 4: Convert Selection to Path

This is essential for the text-on-path technique:

  1. Make a selection using any method
  2. Right-click and choose "Make Work Path"
  3. Set Tolerance to 1.0 for smoother paths
  4. The path will appear in the Paths panel

💡 Tip: Save Your Selections

You can save your selections to use them again later:

  1. Make a selection
  2. Go to Select → Save Selection
  3. Give it a name and click OK
  4. To use it again later: Select → Load Selection

Why this is useful: You can apply different effects to the same area without having to select it again.

Threshold and Text on Path Technique

William Larson-Style Text Effects

Create striking high-contrast images with text on paths, inspired by William Larson's teleprinter work:

What is Threshold? An adjustment that converts your image to pure black and white with no gray tones. Perfect for creating stark contrast like Larson's teleprinter art.

Threshold and Text on Path Tutorial

Watch this tutorial to learn how to add text to a path in Photoshop

⚠️ Important: Before You Start

First, duplicate your layer (Ctrl/Cmd+J) to keep your original image safe.

Step 1: Apply Threshold Effect
  1. Select your duplicated layer
  2. Go to Image → Adjustments → Threshold
  3. Move the slider until you have good black/white balance
  4. Click OK
Step 2: Create a Path from Your Image
  1. Use the Magic Wand tool (W) to select black or white areas
  2. Right-click the selection and choose "Make Work Path"
  3. Set Tolerance to 1.0 for smooth paths
  4. Now you have a path that follows your image shapes
Step 3: Add Text on the Path
  1. Select the Type tool (T)
  2. Move your cursor near the path until it changes to a curved text icon
  3. Click on the path and start typing
  4. Add quotes, references, or your own writing
  5. Use a typewriter font like Courier or Orator Std
Step 4: Blend Text with Image
  1. Try different blend modes for your text layer
  2. Multiply: Text integrates with dark areas
  3. Screen: Text shows up on dark backgrounds
  4. Overlay: Creates high contrast effect
  5. Adjust opacity to make text subtle or bold

Additional Special Effects

Other Useful Filters

Sketch → Photocopy

Makes your image look more like a photocopy

Stylize → Find Edges

Shows just the edges in your image

Artistic → Cutout

Creates a poster-like effect

Distort → Glass

Makes your image look wavy

Try these after applying the Threshold effect for more variety in your designs.

Smart Objects Tip

Convert your layers to Smart Objects before applying filters:

  1. Right-click on your layer
  2. Select "Convert to Smart Object"
  3. Now apply filters - they'll be non-destructive
  4. You can change or remove filters later
  5. Double-click filter name in Layers panel to edit settings

Remember: Smart Objects keep your original image quality intact!

Blend Modes for Combining Images

Blend Modes for Combining Images

Blend modes help you combine different layers in interesting ways:

What are blend modes? Blend modes change how layers mix together. They can make colors darker, lighter, or create special effects when layers overlap.

Best Blend Modes for Text on Path

Multiply

Makes text blend into dark areas - good for white text

Screen

Makes text stand out on dark backgrounds - good for black text

Overlay

Creates high contrast text that adapts to background

Difference

Creates negative-like text effects

Hard Light

Makes text stand out with maximum contrast

How to Layer Images for Good Results

Base Layer Strategy
  1. Start with your main photocopier experiment
  2. Apply Threshold to create high contrast
  3. Add different text paths on separate layers
  4. Apply different blend modes to text layers
Multiple Text Layer Strategy
  1. Create multiple text paths following different contours
  2. Use different fonts and sizes for variety
  3. Add quotes, references, and your own words
  4. Apply different blend modes to each text layer
  5. Adjust opacity for text layers to control prominence

What is This Workshop?

You will create text on path effects using photocopier or scanner experiments. The text will follow the shapes in your images.

Key Terms:
  • Threshold — Makes image pure black and white (no gray)
  • Path — A line that text can follow
  • Text on Path — Text that follows a shape or line
  • Photocopier Art — Using a copier to make creative images
  • Scanner Art — Using a scanner to capture objects directly

TASK 1: Apply Threshold & Create Paths

Make your image high contrast and create paths for text.

Steps to Follow

1
Set Up Your Document
  • Create a new document: File → New
  • Set size to A3, resolution 300dpi
  • Import your photocopier or scanner experiment
  • Duplicate your layer: Ctrl/Cmd + J

💡 Pro Tip

Always work on a duplicate layer to keep your original safe!

2
Apply Threshold
  • Select your duplicated layer
  • Go to Image → Adjustments → Threshold
  • Move the slider to adjust black/white balance
  • Click OK when happy with the result
What Threshold Does: Makes your image pure black and white with NO gray tones. This creates clear shapes that are perfect for paths.
3
Make Selections
  • Select the Magic Wand tool: W
  • Click on black or white areas you want to use
  • Hold Shift to add more areas
  • Look for interesting shapes for text
4
Convert Selection to Path
  • With selection active, right-click
  • Choose Make Work Path
  • Set Tolerance to 1.0 pixels
  • Click OK
Can't see your path? Go to Window → Paths to show the Paths panel.
5
Save Your Path
  • In the Paths panel, double-click "Work Path"
  • Give it a name (e.g., "Text Path 1")
  • This saves your path so you won't lose it

TASK 2: Add Text on Path

Add text that follows the shapes in your image.

Steps to Follow

1
Select the Type Tool
  • Press T for the Type tool
  • Make sure your path is selected in the Paths panel
2
Position on Path
  • Move your cursor near the path
  • Wait for cursor to change to a curved text icon
  • Click on the path where you want text to start
Cursor not changing? Make sure your path is selected in the Paths panel first.
3
Type Your Text

Your text will follow the path! Try these ideas:

  • Artist quotes — From artists that inspire your work
  • Poetry fragments — Lines that connect to your theme
  • Keywords — Related to your Term 2 project
4

TASK 3: Apply Blend Modes & Add References

Style your text and add proper artist citations.

Steps to Follow

1
Apply Blend Modes to Text
  • Select your text layer in the Layers panel
  • Find the blend mode dropdown (says "Normal")
  • Try different blend modes
  • Adjust opacity if needed
2
Choose a Blend Mode
Multiply
Darkens - good for white backgrounds
Screen
Lightens - good for dark backgrounds
Overlay
High contrast effect
Difference
Dramatic color inversion
3
Add Artist References

Add proper citations to your design:

"A constant focus of [my work] was the challenge to conceptualize 'time' through the essentially static medium of photography,"

— William Larson (1978)

Larson, W. (1978) Fireflies [Teleprinter prints]. MoMA, New York.

  • Add artist name with the quote
  • Include Harvard reference at bottom of design
4
Final Adjustments
  • Check text is readable
  • Adjust colors if needed
  • Position elements well
  • Save your PSD with all layers

In this class, you will learn how to edit photocopier images using Photoshop to create interesting text effects that follow the contours of your image. This technique is perfect for adding context, quotes, and references to your design projects.

Key Terms:
  • Photocopier: A machine that makes copies of documents and images
  • Digital editing: Changing images using computer software
  • Threshold: Converting an image to pure black and white with no gray
  • Path: A line or shape that text can follow
  • Text on Path: Making text follow the contours of a shape or line

Complete Workflow

1
Prepare Your Image

Start by creating a new document and importing your photocopied image:

  1. Create a new document (A3 size, 300dpi)
  2. Import your photocopied experiment
  3. Duplicate your layer (Ctrl/Cmd+J) to keep the original safe
Important: Always work on a duplicate layer to preserve your original image.
2
Apply Threshold Effect

Create high-contrast black and white with the Threshold adjustment:

  1. Select your duplicated layer
  2. Go to Image → Adjustments → Threshold
  3. Move the slider to adjust the black/white balance
  4. Click OK to apply

This creates pure black and white contrast with no gray tones, perfect for making clear paths for text to follow.

3
Make Selections & Create Paths

Select areas of your image and convert them to paths:

  1. Use the Magic Wand tool (W) to click on black or white areas
  2. Hold Shift to add more areas if needed
  3. Right-click on your selection and choose Make Work Path
  4. Set Tolerance to 1.0 pixels for smoother paths
  5. Click OK

Your selection is now converted to a path that text can follow. The path will appear in the Paths panel.

4
Add Text on Path

Make your text follow the path you created:

  1. Select the Type tool (T)
  2. Move your cursor near the path until it changes to a curved text icon
  3. Click on the path to position your text
  4. Type your text - it will follow the contours of the path
  5. Choose a font like Courier or Orator Std for a typewriter effect
Tip: If your cursor doesn't change to the "on path" icon, make sure your path is selected in the Paths panel.
5
Apply Blend Modes

Use blend modes to integrate your text with the image:

  1. Select your text layer in the Layers panel
  2. Try different blend modes from the dropdown menu:
    • Multiply: Good for dark text on light backgrounds
    • Screen: Good for light text on dark backgrounds
    • Overlay: Creates high-contrast effect
  3. Adjust layer opacity to control the effect strength
6
Add Quotes and References

Add artist quotes and proper citations to your work:

  1. Create additional text paths using different contours in your image
  2. Add artist quotes with quotation marks and attribution
  3. Include formal Harvard references in typewriter font
  4. Position references near the bottom of your composition

Troubleshooting Text on Path

Problem: Text cursor doesn't change

When your cursor doesn't show the "curved text" icon near a path:

  1. Make sure your path is visible in the Paths panel
  2. Click on the path in the Paths panel to select it
  3. Verify that the Type tool (T) is selected
  4. Try moving closer to the path - the cursor should change
Remember: Paths created from high-contrast images (after Threshold) work best.
Problem: Text appears but looks wrong

When your text doesn't follow the path correctly:

  1. The path might be too complex with too many anchor points
  2. Try using the Direct Selection tool (white arrow) to simplify the path
  3. Delete unnecessary anchor points
  4. Adjust the position of existing points to smooth the path
Tip: Sometimes drawing your own path with the Pen tool gives better results than converted selections.
Problem: Text is hard to read

When your text doesn't stand out from the background:

  1. Try changing the text color for better contrast
  2. Experiment with different blend modes
  3. Add a stroke around the text (right-click layer → Blending Options)
  4. Try adjusting the text opacity
For quotes: Consider adding a semi-transparent rectangle behind important text.

Blend Modes for Text Integration

Best Blend Modes for Text on Path

Multiply

Makes text blend into dark areas - good for white text

Screen

Makes text stand out on dark backgrounds - good for black text

Overlay

Creates high contrast text that adapts to background

Difference

Creates negative-like text effects

Hard Light

Makes text stand out with maximum contrast

Smart Objects Tip

Convert your layers to Smart Objects before applying filters:

  1. Right-click on your layer
  2. Select "Convert to Smart Object"
  3. Now apply filters - they'll be non-destructive
  4. You can change or remove filters later
  5. Double-click filter name in Layers panel to edit settings

Remember: Smart Objects keep your original image quality intact!

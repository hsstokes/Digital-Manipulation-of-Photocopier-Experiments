Digital Editing of Photocopier Images

In this class, you will learn how to edit photocopier images using Photoshop. You will make your images more interesting for your design projects.

Key Terms:
  • Photocopier: A machine that makes copies of documents and images
  • Digital editing: Changing images using computer software
  • Selection: Choosing specific parts of an image to edit
  • Filter: Special effects that change how an image looks
  • Layer: Different parts of an image that can be edited separately

How to Select Parts of Images

Selection Tools for Precise Editing

In today's class, you will learn how to select specific parts of your photocopier experiments:

What is a selection? A selection is like drawing a line around part of your image. This lets you edit only that part without changing the rest of your image.
Tool 1: Object Selection Tool

This tool helps you select objects quickly:

  1. Select Object Selection Tool (W, then toggle)
  2. Draw a box around the object
  3. Photoshop will automatically select it
  4. Hold Shift to add more objects
  5. Hold Alt/Option to remove parts
Tool 2: Select Subject

This tool uses AI to find the main subject:

  1. Go to Select → Subject
  2. Photoshop will find the main objects
  3. Good for selecting scanned items
  4. You can improve it with Select and Mask
Tool 3: Select and Mask

This helps you make better edges:

  1. First select something with any tool
  2. Click Select and Mask button
  3. Use Refine Edge Brush on difficult edges
  4. Choose "Output To: Layer Mask"
  5. Click OK
Tool 4: Color Range

Select areas based on color:

  1. Go to Select → Color Range
  2. Click on a color in your image
  3. Adjust "Fuzziness" slider to select more or less
  4. Good for selecting light areas in photocopies

💡 Tip: Save Your Selections

You can save your selections to use them again later:

  1. Make a selection
  2. Go to Select → Save Selection
  3. Give it a name and click OK
  4. To use it again later: Select → Load Selection

Why this is useful: You can apply different effects to the same area without having to select it again.

Filter Gallery for Special Effects

Filter Gallery for Creative Effects

The Filter Gallery lets you add special effects to your photocopier experiments:

What is a filter? A filter is an effect that changes how your image looks. Filters can make your image look like a sketch, painting, or add texture.

⚠️ Important: Smart Objects First

Before using filters, convert your layer to a Smart Object:

  1. Right-click on your layer
  2. Select "Convert to Smart Object"
  3. This lets you change or remove filters later

How to Open Filter Gallery

  1. Select your layer or make a selection
  2. Go to Filter → Filter Gallery
  3. A window will open showing filter options

Filter Gallery Window

  1. Left: List of filter types
  2. Center: Preview of your image with the effect
  3. Right: Settings for the selected filter
  4. Bottom: List of applied filters

Best Filters for Photocopier Art

Artistic → Cutout

Creates a poster-like effect:

  • Number of Levels: 4-6
  • Edge Simplicity: 2-4
  • Edge Fidelity: 1-2
Sketch → Photocopy

Makes your image look more like a photocopy:

  • Detail: 5-10
  • Darkness: 10-20
  • Good for making photocopier effects stronger
Stylize → Find Edges

Shows just the edges in your image:

  • No settings to adjust
  • Try using on a copy of your layer
  • Set layer blend mode to Multiply or Overlay
Distort → Glass

Makes your image look wavy like through glass:

  • Distortion: 5-15
  • Smoothness: 3-7
  • Texture: Frosted
  • Scaling: 50-100%

Applying Filters to Specific Areas

Why apply filters to specific areas?

  • Makes important parts stand out
  • Keeps some areas clear and easy to see
  • Creates more interesting designs
  • Looks more professional

How to apply filters to specific areas:

  1. Select an area before applying filter
  2. Or apply filter to whole layer, then add mask
  3. Or duplicate layer, apply filter, then erase parts
  4. Or use Filter Gallery mask controls

Layer Masks to Control Effects

Layer Masks

Layer masks help you control where effects appear in your image:

What is a layer mask? A layer mask is like using invisible paint to hide parts of a layer. You can show or hide different parts of an effect.
Basics: Adding a Mask
  1. Select your layer
  2. Click the "Add Layer Mask" button at bottom of Layers panel
  3. A white square appears next to your layer
  4. Paint with black brush to hide parts of layer
  5. Paint with white brush to show parts of layer

Remember: "Black hides, white shows"

Gradient Masks
  1. Add a layer mask
  2. Select Gradient Tool (G)
  3. Choose black-to-white gradient
  4. Click and drag across your mask
  5. Creates a smooth fade between visible and hidden areas
Creating Depth with Masks
  1. Apply a filter to your photocopier image
  2. Add a layer mask
  3. Select a soft brush with low opacity (20-30%)
  4. Paint with black to gradually show original areas
  5. This creates a feeling of depth in your image
Selection-Based Masks
  1. Make a selection using any selection tool
  2. Add a layer mask - your selection automatically applies
  3. Adjust mask with Brush tool if needed
  4. Good for complex shapes in photocopier images

Layer Mask Tips

View the Mask: Alt/Option+click on mask to see it

Invert the Mask: Ctrl/Cmd+I when mask is selected

Make Edges Better: Select mask and use Select and Mask

Turn Off/On: Shift+click on mask

Blend Modes for Combining Images

Blend Modes for Combining Images

Blend modes help you combine different layers in interesting ways:

What are blend modes? Blend modes change how layers mix together. They can make colors darker, lighter, or create special effects when layers overlap.

Best Blend Modes for Photocopier Art

Multiply (正片叠底)

Makes image darker, good for layering photocopied textures

Screen (滤色)

Makes image lighter, good for creating light effects

Overlay (叠加)

Increases contrast while keeping highlights and shadows

Difference (差值)

Creates negative-like effects

Hard Light (强光)

Makes edges and textures stand out

How to Layer Images for Good Results

Base Layer Strategy
  1. Start with your main photocopier experiment
  2. Add research images on separate layers
  3. Apply blend modes to make layers work together
  4. Use masks to show/hide specific areas
Effect Layer Strategy
  1. Duplicate your base layer
  2. Apply filter to the duplicate layer
  3. Change blend mode of the filtered layer
  4. Adjust opacity to control how strong it is
  5. Add mask to apply effect to specific areas
Text Integration Strategy
  1. Create text layer with quote/reference
  2. Position text in a good location
  3. Try different blend modes for text layer
  4. Try Overlay or Soft Light for subtle text
  5. Use layer effects to make text stand out

Adding Text and References

Adding Text and Citations

Adding text and references is important for academic work and creates a professional design:

Adding Artist Quotes

  1. Create new text layer (T key)
  2. Select a good font (see list below)
  3. Type or paste your quote
  4. Make quote text italic
  5. Add quotation marks and artist name
  6. Add a semi-transparent background for better reading

"I became interested in the idea that you could send image information over telephone lines... and that you could interfere with that information."

— William Larson (1978)

Harvard References

  1. Create new text layer
  2. Use a typewriter font (Courier, Andale Mono)
  3. Include full Harvard reference format:

Larson, W. (1978) Fireflies [Teleprinter prints]. The Museum of Modern Art, New York.

Tillmans, W. (2014) Paper Drop [Photographic print]. Tate Modern, London.

Guyton, W. (2007) Untitled [Digital print on linen]. The Museum of Modern Art, New York.

Good Fonts to Use

Recommended Fonts:

Andale Mono - clean look for references

Orator Std - good spacing, good for quotes

Typewriter Condensed - looks good with photocopied materials

Text Styling Tips
  • Use the same text alignment throughout (left alignment is usually best)
  • Use black or dark gray text - it's easiest to read
  • Add semi-transparent boxes behind text to make it readable
  • Group text layers with their backgrounds
Text Effects
  • Try Drop Shadow effect to make text stand out
  • Try low-opacity Outer Glow for a soft look
  • Don't use too many decorative effects
  • A thin Stroke effect can help text stand out on busy backgrounds

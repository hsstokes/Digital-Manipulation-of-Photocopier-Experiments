Advanced Selection Techniques

Selection Tools for Precise Editing

In today's class, we'll focus on making precise selections to apply effects to specific parts of your photocopier experiments:

Tool 1: Object Selection Tool

Quickly select elements in your composition:

  1. Select Object Selection Tool (W, then toggle)
  2. Draw rectangle around element
  3. Photoshop automatically selects the object
  4. Hold Shift to add to selection
  5. Hold Alt/Option to subtract
Tool 2: Select Subject

AI-powered automatic subject selection:

  1. Go to Select → Subject
  2. Photoshop analyzes and selects main elements
  3. Perfect for isolating scanned objects
  4. Refine with Select and Mask if needed
Tool 3: Select and Mask

Refine selections for complex edges:

  1. Make initial selection with any selection tool
  2. Click Select and Mask in options bar
  3. Use Refine Edge Brush to improve edges
  4. Adjust "Output To" options (Layer Mask recommended)
  5. Click OK to apply
Tool 4: Color Range

Select areas based on color similarity:

  1. Go to Select → Color Range
  2. Use eyedropper to select target color
  3. Adjust Fuzziness to control selection range
  4. Perfect for selecting light areas in photocopies

💡 Pro Tip: Save Your Selections

Save complex selections to reuse them later:

  1. Make your selection with any method
  2. Go to Select → Save Selection
  3. Name your selection and click OK
  4. To load it later: Select → Load Selection

Why this matters: You can apply different filters to the same area without having to reselect it each time.

Filter Gallery Techniques

Filter Gallery for Creative Effects

The Filter Gallery is perfect for enhancing photocopier experiments with artistic effects:

⚠️ Important: Smart Objects First

Before applying filters, convert your layer to a Smart Object:

  1. Right-click on layer
  2. Select "Convert to Smart Object"
  3. Now filters will be non-destructive and adjustable

Opening Filter Gallery

  1. Select your layer or a specific selection
  2. Go to Filter → Filter Gallery
  3. The gallery interface opens with preview

Filter Gallery Interface

  1. Left: Filter category folders
  2. Center: Preview of effect
  3. Right: Settings for selected filter
  4. Bottom: Layer stack of applied filters

Recommended Filters for Photocopier Aesthetics

Artistic → Cutout

Creates a posterized effect that enhances photocopier aesthetics:

  • Number of Levels: 4-6
  • Edge Simplicity: 2-4
  • Edge Fidelity: 1-2
Sketch → Photocopy

Simulates photocopier artifacts and enhances existing ones:

  • Detail: 5-10
  • Darkness: 10-20
  • Perfect for emphasizing already photocopied elements
Stylize → Find Edges

Creates line-drawing effect from edges in your photocopies:

  • No adjustable settings
  • Try applying to duplicate layer
  • Set layer blend mode to Multiply or Overlay
Distort → Glass

Creates warped, distorted areas similar to movement in photocopier:

  • Distortion: 5-15
  • Smoothness: 3-7
  • Texture: Frosted
  • Scaling: 50-100%

Selective Filter Application

Why apply filters selectively?

  • Creates focal points in your composition
  • Maintains clarity in important areas
  • Adds visual interest through contrast
  • Creates layered, professional results

Methods for selective application:

  1. Make a selection before applying filter
  2. Apply filter to whole layer, then add layer mask
  3. Duplicate layer, apply filter, then erase parts
  4. Use Filter Gallery mask controls

Layer Masking for Controlled Effects

Layer Masking Essentials

Layer masks are crucial for controlling where effects appear in your composition:

Basics: Adding Layer Masks
  1. Select your layer
  2. Click the "Add Layer Mask" button at bottom of Layers panel
  3. A white mask thumbnail appears next to layer
  4. Paint with black brush to hide parts of layer
  5. Paint with white brush to reveal parts of layer

Remember: "Black conceals, white reveals"

Technique: Gradient Masks
  1. Add a layer mask
  2. Select Gradient Tool (G)
  3. Choose black-to-white gradient
  4. Click and drag across mask to create smooth transition
  5. Perfect for blending filters gradually
Advanced: Creating Atmosphere
  1. Apply a filter to enhance your photocopier experiment
  2. Add a layer mask
  3. Select a soft, low-opacity brush (20-30%)
  4. Paint with black to reveal original areas gradually
  5. Create depth and focus in your composition
Technique: Selection-Based Masks
  1. Make a selection using any selection tool
  2. Add a layer mask - selection automatically applies to mask
  3. Adjust mask with Brush tool as needed
  4. Perfect for complex shapes in photocopier images

Layer Mask Editing Tips

View the Mask: Alt/Option+click on mask thumbnail to view it

Invert the Mask: Ctrl/Cmd+I when mask is selected

Refine Edges: Select mask and use Select and Mask

Disable/Enable: Shift+click on mask thumbnail

Blend Modes for Combining Elements

Blend Modes for Combining Elements

Blend modes are essential for creating rich, layered compositions with your photocopier experiments:

Key Blend Modes for Photocopier Art

Multiply

Darkens image, perfect for layering photocopied textures

Screen

Lightens image, good for creating glow effects

Overlay

Increases contrast while preserving highlights and shadows

Difference

Creates inverted, negative-like effects

Hard Light

Intense contrast, makes edges and textures pop

Layering Strategies for Complex Compositions

Base Layer Strategy
  1. Start with main photocopier experiment
  2. Add research images on separate layers
  3. Apply blend modes to integrate layers
  4. Use masks to reveal/hide specific areas
Effect Layer Strategy
  1. Duplicate your base layer
  2. Apply filter to duplicate layer
  3. Change blend mode of filtered layer
  4. Adjust opacity to control intensity
  5. Add mask to apply effect selectively
Text Integration Strategy
  1. Create text layer with quote/reference
  2. Position text appropriately
  3. Experiment with blend modes for text layer
  4. Try Overlay or Soft Light for subtle text
  5. Use layer effects for additional emphasis

Adding Text and References

Integrating Text and Citations

Adding properly formatted text and references is essential for academic integrity and creates a professional research document:

Adding Artist Quotes

  1. Create new text layer (T key)
  2. Select appropriate font (see recommendations below)
  3. Type or paste your quote with attribution
  4. Format with italics for the quote
  5. Add quotation marks and attribution
  6. Consider adding a semi-transparent background rectangle

"I became interested in the idea that you could send image information over telephone lines... and that you could interfere with that information."

— William Larson (1978)

Harvard References

  1. Create new text layer
  2. Use a monospaced font (Courier, Andale Mono)
  3. Include full Harvard reference format:

Larson, W. (1978) Fireflies [Teleprinter prints]. The Museum of Modern Art, New York.

Tillmans, W. (2014) Paper Drop [Photographic print]. Tate Modern, London.

Guyton, W. (2007) Untitled [Digital print on linen]. The Museum of Modern Art, New York.

Typography Considerations

Recommended Fonts:

Andale Mono - clean, technical look for references

Orator Std - balanced spacing, good for quotes

Typewriter Condensed - pairs well with photocopied materials

Text Styling Tips
  • Use consistent text alignment (left alignment usually works best)
  • Consider text color carefully - black or dark gray is most readable
  • Add semi-transparent background shapes behind text for legibility
  • Group text layers with their backgrounds
Text Effects
  • Try subtle Drop Shadow effect for emphasis
  • Experiment with low-opacity Outer Glow for ethereal quality
  • Avoid overly decorative effects that compromise legibility
  • Subtle Stroke effect can help text stand out on busy backgrounds
